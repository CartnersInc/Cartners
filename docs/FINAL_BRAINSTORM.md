# Final team brainstorm — source record

Transcribed from the user-supplied two-page Product Feature Design Doc Brainstorm PDF, received October 17, 2026. This records the team's feature list; it does not claim these features are implemented. Implementation scope and priorities are in PRD.md.

## Minimalist Homepage

- AI search box for groceries/recipes: input a recipe, suggest changes such as removing allergens, improving health, or giving ideas.
- Tabs for pages.
- Recent activity / quick access feed.

## Plans Page

- Calendar of meal plans.
- User preferences.
- Automated weekly meal plan generator.

## Shopping Page

- Grocery store integration: nearest grocery stores and cheapest prices among those nearby stores.
- Suggestions.
- Who buys what.
- Shared collaborative cart.
- Individual or sharing options.

## Payment/Spending Page

- Who paid for what.
- Who owes each other what.
- Link to pay via Venmo or PayPal.
- Automatic expense splitting calculations.

## Household/Group Page

- “I'm going to X grocery store, please tell me what you want in the next Y minutes.”
- Push notifications / web-app notification of the store run, a countdown, and additions to the list.
- Manage groups you are in.
