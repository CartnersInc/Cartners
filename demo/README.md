# Interface prototype

From the repository root, run `python3 -m http.server 4173 --directory demo/dist` and open http://localhost:4173. In this directory, `npm test` checks the model rules. No install or build step is needed.

This is the existing interaction baseline. Read ../docs/UX_REVIEW.md before adding features. Browser-local data, curated recipe examples, simulated AI and payment handoff; no live backend or real transfers.
